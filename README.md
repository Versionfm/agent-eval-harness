# Agent Eval Harness

A project for building a harness to evaluate coding agents on realistic repository tasks, using the private `Versionfm/algo-trading-agent` repository as the initial candidate environment.

## Status

Design interview in progress. There is no harness implementation or verified benchmark result yet.

The starting idea is to measure agent performance on coding tasks drawn from an existing project. Target users, task scope, evaluation rules, execution boundaries, and the first milestone will be decided during the interview.

See [the design interview](docs/design-interview.md) for confirmed scope and open questions.
